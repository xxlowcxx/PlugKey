# Plug Key

A USB that talks by how many times it is inserted.

| | |
| --- | --- |
| What it is | The USB. Insertion count is the signal. |
| Started as | A second insertion on one stick. It became an emergency language for a failed or locked-out system. |
| What it is not | IPP. A password file. A bypass. |
| The language | [IPP](https://github.com/xxlowcxx/IPP). Insertion Plug Presence, the insertion language. It has its own repo. |
| Status | Inventory and owned-hardware design. Code comes back in a later push. |
| Owner | LowC. Toolaid. |

A physical insertion is not a setting a program can mute.

## Mission

Repush the code and finish Plug Key. A bypass stays off this page.
